# 快递分片

三个快递员分十几个村的分片调度板，纯前端单页应用（无构建、无依赖）。
浏览器直接打开 `index.html` 即可，数据存在 localStorage。

## 文件

- `index.html` — 页面结构
- `styles.css` — 样式
- `app.js` — 状态、分片算法与交互（算法部分可被 Node 直接 require 单测）

## 功能对应

1. **村子登记**：村名、路况（柏油/水泥/砂石/泥泞/山路）、往返分钟、日均件量、早晚班车、到站时间，直接在表格里改。
2. **实时统计**：每个快递员早班/晚班的往返总时长、总件量、进度条随分村实时更新。
3. **早晚班硬隔离**：早班车村和晚班车村是两个分池，独立登记、独立均衡，永远不会混分。
   班车到站时间改到跨午（早↔晚）时，该村自动从原片区摘下，横幅提示重新分。
4. **班车/路况变动后稳片重划**：顶部「稳片重划」从现有划法出发做爬山优化，
   每个村换主带“搬迁代价”，只有改善足够大才动熟片；「全自动均衡」则无视旧片追求最均衡。
5. **请假拆片**：快递员请假后其村自动拆给在岗者，变动记录和基线对比里用 +N分/+N件 标出谁变重；归位按请假前快照还原。
6. **多方案对比**：可新建/复制划法，「方案并排比」列出每人每班时长、件量、超时与极差，系统只摆数据，公平由人判。
7. **时间窗口变化**：顶部可改每班派送起止时间或选 3/4/4.5/5 小时预设，超窗口的班次红条提示，再点「稳片重划」尽量少动熟片。

## 负荷模型

单村工作量 = 往返分钟 + 派件耗时（每单 2.5 分钟，单村封顶 30 分钟）。
均衡以工作量极差为主、件量极差为辅；加班判定只看往返总时长是否超过窗口分钟数。
