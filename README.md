# 快递分片 · 镇村派送分区工具

三个快递员分十几个村的纯网页小工具：村子、路况、件量、班车时间摆在一起，一片片分。
无需安装、无需联网、无需后端，浏览器直接打开 `index.html` 即可使用，数据存在本地 localStorage。

## 运行

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

## 三个页签

**① 村子与路况**
- 按村登记：村名、路况（柏油/水泥/山路，路况差的路耗时按系数折算）、往返时间、日均件量、早/晚班车、到镇时间。
- 派送时间窗口可改（件到镇上起算），改完可「保留熟片微调重划」或「全部重新均衡」。
- 快递员姓名、颜色可编辑，可增删（至少留一人）。

**② 分片调度**
- 每人的卡片分「☀️早班车片 / 🌙晚班车片」两段，实时显示总时长、总件量、村数；最忙标红、最闲标绿，超出时间窗口红色提示。
- 作业时长 = 往返时间 × 路况系数（好路1.0 / 一般1.2 / 难走1.5）+ 件量 × 1.5 分钟。
- **晚班车单独安排**：可指定一人专跑晚班片，他不再拿早班村，其他人也不拿晚班村，早晚严格不混分。
- **班车时间一变**：「批量改班车…」勾选受影响村改批次/到镇时间，只重划受影响的批次，其余熟片不动；越界指派自动作废重分。
- **有人请假**：请假人的村自动拆给其他人，接过来的村打紫色「代班」标记，卡片上直接看到 `代班 +N件 / +N分`；销假时代班村自动归还本人。
- 「自动均衡分片」支持两种模式：保留熟片（只动必须动的村）/ 全部重新均衡（重活先派、每步给最闲的人的贪心算法）。
- 每个村可在下拉里手动换人（不符合早晚不混分/请假约束的人不可选）；未分配村有一键重分。

**③ 方案对比**
- 几套划法卡片并排：每人时长、件量、代班增量、是否超窗口；忙闲差（最忙-最闲分钟数）越小越公平。
- 下方公平性明细表用条形图标出最均衡 / 差距最大的方案，公不公平由人判。
- 方案可在分片页「复制一套」后微调，互相对照且互不影响。

## 文件

- `index.html` — 页面骨架
- `app/styles.css` — 样式
- `app/data.js` — 数据模型、示例数据、持久化、分片/请假/公平性算法
- `app/app.js` — 三个页签的界面与交互
